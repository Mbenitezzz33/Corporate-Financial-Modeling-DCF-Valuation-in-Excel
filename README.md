# Corporate Financial Modeling, DCF & Valuation in Excel

An integrated Excel-based financial analysis and valuation model examining
Dell Technologies and Microsoft.

Originally developed from corporate finance coursework and subsequently
rebuilt and expanded into a comprehensive financial modeling project, the
workbook connects historical financial statement analysis with working-capital
analysis, free cash flow, cost of capital, capital budgeting, and discounted
cash flow valuation.

A companion methodology manual documents the financial relationships,
formulas, and valuation framework used throughout the model.

## Project Overview

The workbook is designed to demonstrate the progression from reported
financial statements to forward-looking valuation:

**Financial Statements → Operating Performance → Working Capital → Cash Flow
→ FCFF → Cost of Capital → DCF → NPV**

The analysis includes:

- Historical financial statement analysis for Dell Technologies and Microsoft
- Profitability and operating-performance metrics
- Working-capital and operating-efficiency analysis
- Cash flow from operations, free cash flow, and FCFF
- CAPM-based cost of equity estimation
- Cost of debt and capital-structure analysis
- Weighted Average Cost of Capital (WACC)
- Five-year hypothetical capital expenditure projects
- Discounted unlevered free cash flow
- Net Present Value (NPV)
- Supporting valuation methodology and financial-modeling documentation

## Cost of Capital & WACC

Separate cost-of-capital models estimate the required returns associated with
debt and equity and combine them according to the modeled capital structure.

<img width="1257" height="725" alt="Dell_WACC-G1" src="https://github.com/user-attachments/assets/c0a17a1d-d508-4053-9475-575720780859" />


The workbook incorporates the risk-free rate, equity beta, market risk
premium, debt risk, market value of equity, net debt, taxes, and capital
structure weights to estimate WACC.

## DCF & Capital Budgeting

The workbook applies the financial analysis and cost-of-capital framework to
hypothetical five-year capital expenditure projects.

These scenarios are designed to demonstrate capital-budgeting methodology and
do **not** represent actual or announced projects by Dell Technologies or
Microsoft.

Forecast operating assumptions are converted into FCFF and discounted using
the applicable WACC.


<img width="2154" height="1105" alt="DCF_MSFT-1" src="https://github.com/user-attachments/assets/35c5e278-dd42-4e04-b3ba-96c4bcd02835" />


The finite-project model explicitly forecasts Years 1–5, incorporates the
initial investment at Year 0, recovers remaining net working capital in the
final year, and does not assume a terminal value.

---

## Net Present Value

Project cash flows are evaluated using NPV to determine whether the present
value of expected future cash flows exceeds the required initial investment.

<img width="1536" height="1024" alt="NPV-G1" src="https://github.com/user-attachments/assets/1da1e478-ed2b-4012-9522-c4185c9f792f" />


The model uses the standard decision framework:

- **NPV > 0:** Project is expected to add value
- **NPV = 0:** Project is expected to break even at the required return
- **NPV < 0:** Project is expected to reduce value

## Workbook Structure

The consolidated Excel workbook contains dedicated analytical sections for:

- Dell Technologies financial statement analysis
- Dell cost of capital / WACC
- Dell DCF and NPV analysis
- Microsoft financial statement analysis
- Microsoft cost of capital / WACC
- Microsoft DCF and NPV analysis

The workbook uses interconnected formulas so that historical financial
performance feeds operating assumptions, cash-flow analysis, cost of capital,
and valuation.

### Excel Modeling Conventions

The workbook follows common financial-modeling conventions:

- **Blue font:** Hard-coded assumptions and inputs
- **Black font:** Formulas and calculated values
- **Green font:** Links to other worksheets
